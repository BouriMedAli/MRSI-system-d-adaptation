Git Branching Guide

Master Branch Management

A Professional Guide to Git Workflow

What You'll Learn

  • Creating and managing branches
  • Working without affecting the main branch
  • Best practices for team collaboration
  • Pull request workflow
Step 1

Clone the Repository

First, get a local copy of your repository


git clone <repository-url>
cd <repository-name>
This creates a local copy of your remote repository

Example


git clone https://github.com/username/my-project.git
cd my-project
Step 2

Ensure You're on Main Branch


git checkout main
Switches your working directory to the main branch
Step 3

Pull Latest Changes


git pull origin main
Downloads and integrates remote changes into your local branch

⚠️ Always do this before creating a new branch!

Step 4

Create and Switch to New Branch


git checkout -b <new-branch-name>
Creates a new branch and switches to it in one command

Branch Naming Conventions


# Feature branches
git checkout -b feature/login-page
git checkout -b feature/user-dashboard

# Bug fix branches
git checkout -b bugfix/auth-error
git checkout -b fix/header-alignment

# Hotfix branches
git checkout -b hotfix/security-patch
Step 5

Make Your Changes

  • Edit existing files
  • Add new features
  • Fix bugs
  • Update documentation

💡 Your changes are isolated in your branch

Step 6

Add and Commit Changes


git add .
git commit -m "Your commit message"

Writing Good Commit Messages


# Good commit messages
git commit -m "Add user authentication feature"
git commit -m "Fix navigation menu overflow on mobile"
git commit -m "Update README with installation instructions"

# Bad commit messages ❌
git commit -m "changes"
git commit -m "fix"
git commit -m "update"

Staging Specific Files


# Add specific files
git add src/app.js
git add styles/main.css

# Add all files in a directory
git add src/

# Add all JavaScript files
git add *.js
Step 7

Push Branch to GitHub


git push origin <new-branch-name>
Uploads your branch and commits to the remote repository

First time pushing? Use: 


git push -u origin <new-branch-name>
Step 8

Create a Pull Request

  1. Go to your GitHub repository
  2. Find your branch
  3. Click "Compare & pull request"
  4. Add description and submit

Pull Request Best Practices

  • Write clear descriptions
  • Link related issues
  • Request reviewers
  • Respond to feedback
  • Keep PRs focused and small
Step 9

Switch Back to Main


git checkout main

After your PR is merged: 


git checkout main
git pull origin main
git branch -d <branch-name>  # Delete local branch

Best Practices Summary

  • ✅ Always pull latest changes before creating a branch
  • ✅ Use meaningful branch names
  • ✅ Commit early and often
  • ✅ Write descriptive commit messages
  • ✅ Regularly push your changes
  • ✅ Keep branches focused on single features
  • ✅ Delete branches after merging

Quick Reference


# Check current branch
git branch

# See all branches (including remote)
git branch -a

# Check status
git status

# View commit history
git log --oneline

# Discard local changes
git checkout -- <file>

# Update branch with main changes
git merge main

Common Issues

Merge Conflicts


# When conflicts occur
git status  # See conflicted files
# Edit files to resolve conflicts
git add .
git commit -m "Resolve merge conflicts"

Forgot to Create Branch


# Made changes on main by mistake?
git stash  # Save your changes
git checkout -b new-feature  # Create new branch
git stash pop  # Apply your changes
git add .
git commit -m "Add feature"

  • Pull requests enable code review
